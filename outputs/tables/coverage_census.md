## 2. Defect: silent player-name aliasing drops a superstar

The join from the 1xbet board to the box score is an exact lowercase string match. It fails for
**8 distinct player strings covering 3,199 board rows (3.9% of the whole prop book)**, and every
one of them is a real, rostered WNBA player rather than an unknown:

| board string | board rows | actual box name | why the match fails |
|---|---|---|---|
| `aja wilson` | 1,530 | A'ja Wilson | apostrophe stripped by the board |
| `awa fam thiam` | 751 | Awa Fam | board appends a second surname |
| `nazahrah hillmon-baker` | 544 | Naz Hillmon | board uses full legal name + married name |
| `janelle illona salaun` | 281 | Janelle Salaun | board inserts a middle name |
| `alexa held` | 38 | Alexa Held (box: 'Held'/'heldon' variants) | spelling variant in the box file |
| `valeriane vukosavljevic` | 20 | Valeriane Ayayi | board uses married surname, box uses maiden |
| `cheyenne parker` | 18 | Cheyenne Parker-Tyus | box appends '-Tyus' |
| `xu han` | 17 | Han Xu | given/family name order reversed |

This is not cosmetic. **A'ja Wilson alone is 1,530 rows, and she is the highest-usage player in the
league.** Every downstream study in this repo that joins the board to the box silently excludes
her, which means:

- the prop-book sample is not a random sample of the board, it is the board **minus its most
  heavily-traded name plus seven others** -- a survivorship hole, not a coverage gap;
- any 'the model has no edge on stars' or 'usage rank' finding computed on this join is
  measured on a population with the top-usage player deleted;
- the live model cannot bet her at all, so its forward record is conditioned on her absence.

Recommended fix (NOT applied here -- this audit is read-only): an alias table plus a fallback
match on accent-folded surname + team, with an assertion that fails loudly when a board name
with more than ~50 rows cannot be resolved. The failure mode to avoid is exactly the one this
codebase already hit with `toks()` accent-folding in the Polymarket fixture lookup.

## 3. Intra-game clustering in the prop book (the same section-44 question, pre-game side)

Gradable two-sided quotes: **7,259** across **132** games (median **49** quotes per game).

A game is one basketball game: if it runs fast, most of that night's overs cash together. So the
quotes inside a game are not independent. I measure the intraclass correlation of the binary
`over won` outcome using the standard one-way ANOVA estimator, at the game block.

| quantity | value |
|---|---|
| base over-hit rate | 0.5045 |
| mean quotes per game (k0) | 54.9 |
| ICC of `over won` within game | **0.0354** |
| design effect 1+(k0-1)*ICC | **2.91** |
| n quotes | 7,259 |
| **n_eff** | **2496** |

Game-block bootstrap of the base over rate: 0.5045, 95% CI [0.4852, 0.5234], SE 0.0097.
Naive iid SE would be 0.0059. Ratio 1.65, so the design effect measured directly is **2.74x** --
consistent with the ICC estimate above.

Practical reading: the prop book's 7,259 quotes carry roughly **2496 independent quotes** of
information. That is a far milder deflation than the in-play feed (45-60x) -- pre-game props
across different players really are mostly independent -- but it is not 1.0, and a study that
quotes an unadjusted t-stat on 7,259 is overstating its precision by about 71%.

### Book margin on the surviving two-sided quotes (methodology law 4)

| quantity | value |
|---|---|
| median two-sided overround | **7.50%** |
| mean overround | 7.57% |
| p10 / p90 overround | 5.78% / 9.29% |
| median breakeven hit rate needed on the Over (1/odds) | **53.48%** |
| median breakeven hit rate needed on the Under | 53.48% |
| observed base Over hit rate | 50.45% |
| flat-bet ROI, blind Over on every quote | **-5.80%** |
| flat-bet ROI, blind Under on every quote | **-8.21%** |

The board carries a median **7.5%** overround, so an Over needs about **53.5%** to break even
and it actually lands **50.4%**. That 3.0-point shortfall is the house edge, and it is the
hurdle any claimed signal must clear -- **not 50%**. Blind flat betting confirms it: every Over
on the board returns **-5.8%** and every Under **-8.2%**, i.e. both sides lose roughly the vig.

Two things follow. First, the base Over rate is **50.45%** -- the board is neither systematically
over-lined nor under-lined, so there is no always-over base-rate artifact to be fooled by
(methodology law 9). Second, the two sides are close to symmetric in cost, so a finding that
appears only on one side and not as its mirror on the other is a red flag, not a discovery.

## 4. The one-month-horizon limitation, with numbers

| horizon fact | value |
|---|---|
| prop-book capture window | 2026-06-24 .. 2026-08-26 (**64 days**) |
| in-play capture window | 2026-07-16 .. 2026-08-11 (**27 days**) |
| 2026 games played league-wide in the whole file | 287 |
| games with at least one gradable prop quote | **132** (46% of played) |
| games with in-play odds | **27** (9% of played) |
| distinct players with a gradable quote | 118 |
| Model S live forward record | 21-27 settled bets |

What one month buys you, in effect size. Using the measured design effect above, the minimum
ROI detectable at 80% power and alpha=0.05, two-sided, on flat 1u bets priced around 1.87:

- n=50 bets (n_eff 17) -> smallest reliably detectable edge **+65.5% ROI**
- n=100 bets (n_eff 34) -> smallest reliably detectable edge **+46.3% ROI**
- n=200 bets (n_eff 69) -> smallest reliably detectable edge **+32.7% ROI**
- n=500 bets (n_eff 172) -> smallest reliably detectable edge **+20.7% ROI**
- n=1,000 bets (n_eff 344) -> smallest reliably detectable edge **+14.6% ROI**
- n=2,000 bets (n_eff 688) -> smallest reliably detectable edge **+10.4% ROI**
- n=7,259 bets (n_eff 2496) -> smallest reliably detectable edge **+5.4% ROI**

So a full month of the entire board -- every player, every market, both sides -- can just about
resolve a **+5.4%** edge. The strategies this project actually runs bet a few times a night:
at n=100 bets nothing below **+46% ROI** is distinguishable from noise, and at n=21 (the live
Model S record) the detectable floor is around **+101% ROI**. A live +6.8% on 21 bets is
therefore consistent with anything from a large edge to a large *negative* one, and is not
evidence of either. This is the single most important number in this audit: **the dataset's
horizon, not the analyst's cleverness, is what caps what can be concluded.**

Three further horizon constraints that no amount of within-window analysis can relieve:

1. **One season, no cross-season replication.** Everything gradable is 2026. `elo_model/` holds
   2019-2025 box and play-by-play, but it carries **no odds for those seasons that match this
   book**, so a signal found here cannot be re-tested on an earlier year.
2. **One slice of one season.** The window is late June to late August: mid-season through the
   run-in. No opening-weeks period (when books are least calibrated and lines move most) and no
   playoffs. Any seasonality is entirely unobserved.
3. **The book is one book.** 1xbet for props, Pinnacle for game markets. A price artifact
   specific to 1xbet's prop pricing is indistinguishable from a real market inefficiency, because
   there is no second prop book to disagree with it -- other than Pinnacle's 6815 prop rows, which
   is exactly the comparison the project's live 'sharp gap' signal already exploits.
